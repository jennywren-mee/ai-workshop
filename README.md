# ai-workshop

Set up
- Open preferred AI model
- Start new conversation 

Task #1
- Ask for a user story for a feature you are familiar with.
  Example: Give me a user story for purchasing a gift card 

Task #2 
- Ask for a user story in the AS A, I WANT, SO THAT format with acceptance criteria

Task #3 
- Ask for the same user story, and add sections you'd expect
  Example: Assumptions, Dependencies, Questions to be answered

Task #4
- Try prompting to improve the formatting of the story that is being produced

Task #5 
- Try different ways to prompt
  Example: Screenshots, AS A I WANT SO THAT format, a URL to break down a page
